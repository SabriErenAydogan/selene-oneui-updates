# selene-oneui-updates

Update index for SabriniumROM on selene (Redmi 10 / Redmi 10 2022).

- `index.json`: read by the built-in updater app (SabriniumROM System) on the phone.
  It lists the available builds with size, SHA-256, download URL, minimum version
  and changelog (EN/TR). Updates are recovery zips installed through OrangeFox.
